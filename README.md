# LEVO KG — Premium Storefront (Next.js App Router)

Концепция интерфейса для LEVO KG: премиальная редакционная подача, крупные интерьерные фотографии, минимальная навигация, крупная типографика, асимметричные категории и аккуратные анимации. Это самостоятельный starter/drop-in reference, не прямое копирование сайта Bang & Olufsen.

## Состав
- `/` — главная страница
- `/catalogs` — каталог категорий и подборка товаров
- `/catalogs/[slug]` — страница категории
- `/products/[slug]` — страница товара
- `/contacts` — контакты
- Адаптивная шапка, мобильное меню, поиск по query-параметру, карточки товаров, навигационные хлебные крошки, footer.

## Запуск
Требуется Node.js 20.9+ (для Next.js 15).

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`.

## Важное перед интеграцией в levo.kg
1. **Не заменяйте текущий проект целиком.** Сначала перенесите стили и компоненты в отдельную ветку Git и адаптируйте их к существующим страницам, Prisma-моделям и сервисам.
2. Демонстрационные товары в `lib/data.ts` — только заглушки. Замените массив `products` данными из вашего Prisma catalog/product service. Не используйте их как реальные цены или складские остатки.
3. В `app/contacts/page.tsx` замените телефон и адрес на актуальные. `hello@levo.kg` тоже проверьте перед публикацией.
4. Изображения загружаются по URL с Unsplash и Google Fonts — для production лучше использовать собственные фото LEVO и локальные/оптимизированные шрифты. Если включите `next/image`, настройте `images.remotePatterns` и используйте `Image`.
5. Кнопка «Добавить в корзину» в этом starter — UI-заглушка с локальным состоянием. Подключите вашу настоящую корзину, оформление заказа и аналитику.
6. Поиск пока отправляет параметр `q` на `/catalogs`; подключите фильтрацию к серверному поиску.
7. Категории в `lib/data.ts` — визуальная демонстрация. В вашем проекте используйте текущие реальные slug, включая существующие категории встраиваемой техники.
8. Если ваш проект использует другую major-версию Next.js, проверьте совместимость перед переносом. Код маршрутов написан под App Router Next.js 15.

## Как подключить реальные данные
- Вынесите серверные запросы в отдельный модуль (`lib/queries.ts`) и используйте ваш `@/lib/prisma` / сервис каталога.
- Сохраняйте существующую SEO-логику, canonical URL, `generateMetadata`, кэширование и revalidation.
- Компоненты с `'use client'` оставляйте для интерактивности; данные каталога по возможности загружайте в Server Components.
